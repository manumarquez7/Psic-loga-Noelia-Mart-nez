# Sentires · demo para cliente

Vista previa de una landing de presentación para la Lic. Noelia Martínez. Es una demo estática: no incluye agenda, formulario, pagos ni panel de administración.

Abrir `index.html` en un navegador. Los estilos, el logo, la fotografía pequeña del perfil y la navegación funcionan sin compilación. La tipografía web usa Google Fonts y tiene una alternativa local.

Antes de compartir como página definitiva, validar con la profesional: nombre, matrícula, fotografía, servicios, modalidades, ubicaciones y datos de contacto. Los botones de WhatsApp, teléfono y correo utilizan los datos incluidos en el HTML de referencia.
